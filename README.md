# maverick-plugins

Marketplace privado de plugins de Adrie Bustos.

| Plugin | Para qué sirve |
|---|---|
| casa-soyer-ecommerce | Ecommerce y pauta de Casa Soyer |
| maestro-claude | Método de Claude Code, Claude Design, webs y agentes (de 201 videos) |
| meta-ads-pro | Meta Ads: ecommerce, SaaS, marca e infoproductos |
| maverick-sistemas | Marca, contenido, prospección, propuestas, overlays y estudio de Reels |
| segundo-cerebro | Guarda en Obsidian lo importante de cada conversación |
| copy-y-estilo | Textos con tu voz, hooks y guiones |

**Para actualizar:** en el repositorio se sube la versión nueva (se sube el número `version` de cada plugin) y en Claude se pulsa **Check for updates** en el marketplace. Si no se cambia la versión, los cambios no llegan.


**En la app de Claude:** Personalización → Plugins → Agregar → **Administrar mercados** → ⋮ junto a `maverick-plugins` → **Buscar actualizaciones**. Procedimiento completo de publicación en la bóveda (`Cómo se actualizan los plugins`). Todos los plugins incluyen la skill `no-improvisar`.
