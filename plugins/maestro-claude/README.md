# maestro-claude

Plugin en español con el método de uso de Claude, Claude Code, Claude Design y Cowork, destilado de 201 videos de Jack Roberts (feb 2023 – oct 2026). Contenido reescrito, sin transcripciones.

**Contiene:** 43 skills (empieza por `metodo-web-unico`) · 5 subagentes (diseñador, arquitecto de Claude Code, constructor web, auditor QA, operador Agentic OS) · 9 comandos (incluye /web) · 1 hook que pide confirmación si intentas escribir una clave en un archivo.

**Módulos:** Claude Design (10 skills) · Claude Code core (11) · Webs y apps (12) · Cowork y Agentic OS (9 tras fusionar duplicados).

**Comandos:** /disenar-web, /auditar-diseno, /iniciar-proyecto, /auditar-tokens, /crear-web, /publicar-web, /brief-matutino, /revisar-seguridad-agente.

**Límites:** el contenido refleja videos hasta el 2026-10-10 y los productos cambian rápido: cada skill marca su vigencia. Las cifras de dinero y resultados del creador no están verificadas y se omitieron. El plugin no trae MCPs ni credenciales; conecta los tuyos. No lo probé instalado.
